Política de privacidad — Canal Silla Ventana

Última actualización: 31 de octubre de 2026

Canal Silla Ventana es una herramienta de uso personal que administra un único canal de YouTube, La Silla Junto a la Ventana, por cuenta de su dueña.

Qué datos usa

Con el permiso que la dueña del canal otorga por Google, la herramienta accede a los datos de ese canal mediante la API de YouTube Data y la API de YouTube Analytics: videos, listas de reproducción, subtítulos, comentarios y estadísticas del canal.

Dónde se guardan

El permiso de acceso y los datos consultados quedan solo en el computador de la dueña del canal. No se envían a servidores propios ni de terceros, no se venden, no se comparten y no se usan con fines publicitarios.

Uso de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado. También aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Cómo revocar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
